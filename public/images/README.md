# Photos for the CA Girls State Guide

Drop real photos here (JPG or WebP). The site will pick them up automatically.

| Filename | Suggested content | Used in |
|----------|-------------------|---------|
| `campus.jpg` | Campus / dorms / UCR exterior | After How It Works |
| `community.jpg` | City meeting, friends, meals | Before The Experience |
| `ceremony.jpg` | Flag raising, closing, traditions | Before What's Next |
| `og-share.png` | 1200×630 share card (optional override) | Social / Open Graph |

Tips:
- Landscape photos work best (roughly 1600×900 or wider)
- Avoid faces if you don't have permission to publish
- Keep file sizes under ~400KB when possible (export compressed)
